# 📡 Lists Epsiquad VPN

Коллекция черных и белых списков для **mihomo** на основе фильтров Adguard.

## 📂 Структура репозитория

```
Lists-Epsiquad-VPN/
├── own/              # Личные кастомные списки
└── mihomo/           # Готовые списки для использования
    ├── mrs/          # Скомпилированные списки (бинарный формат)
    └── txt/          # Текстовые списки (читаемый формат)
```

## 🎯 Описание

### `/own`
Авторские списки, созданные и поддерживаемые вручную для специфических нужд.

### `/mihomo`
Готовые к использованию списки, основанные на фильтрах Adguard:

- **`/mrs`** — скомпилированные списки в бинарном формате, оптимизированные для прямого использования в mihomo, потребляют меньше памяти при использовании.
- **`/txt`** — текстовые версии списков в читаемом формате для просмотра содержимого

## 🚀 Использование

1. Выберите нужный список из директории `/mihomo/mrs`
2. Добавьте ссылку на raw-файл в конфигурацию mihomo
3. Создайте правило под даный список
3. Перезагрузите конфигурацию

## 📌 Источники

Списки основаны на фильтрах [Adguard](https://github.com/AdguardTeam/AdguardFilters).

## 🔄 Обновления

Автоматическая проверка обновлений происходит **каждый час**. Все изменения из upstream источников применяются автоматически.

## ⚠️ Примечание

Если вам нужно посмотреть содержимое списка перед использованием, используйте версии из `/mihomo/txt`.
**Все списки содержат только домены, не готовые правила!**
